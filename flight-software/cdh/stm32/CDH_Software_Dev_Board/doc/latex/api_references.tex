Subscribes a task to topics based on the Subscription Table (\doxylink{subscriptions_8c_sub_table}{sub\+\_\+table})\hypertarget{api_references_autotoc_md2}{}\doxysubsubsubsubsubsection{\texorpdfstring{Notes:\+}{Notes:\+}}\label{api_references_autotoc_md2}

\begin{DoxyItemize}
\item Calling this function does not wake up a task. It is just a normal function call inside the task.
\item You should call this during the setup phase of the task, outside of the infinite loop, so it runs only once.
\item After subscribing, all tasks must call \doxylink{app__events_8c_a07ff4defe7033e21ccfbb62159df4313}{Task\+Sync\+\_\+\+Set\+And\+Wait()} to sync up before moving forward.
\end{DoxyItemize}
