TIM6 callback function. 

Whenever TIM6 overflows, the callback increments the global variable "{}uw\+Tick"{} used as application time base for Cortex-\/\+M7. \begin{DoxyWarning}{Warning}
To prevent interrupt priority inversion and deadlocks, we separate the RTOS timebase from the HAL timebase using TIM6 as the HAL timebase and Sys\+Tick for RTOS
\end{DoxyWarning}

\begin{DoxyEnumerate}
\item Sys\+Tick is dedicated exclusively to the RTOS and is assigned the LOWEST priority so it doesn\textquotesingle{}t block time-\/critical ISRs.
\item A dedicated hardware timer (TIM6) is used for the HAL timebase (HAL\+\_\+\+Delay) and is assigned a HIGH priority. This ensures HAL timeouts can safely execute even when called from within peripheral interrupts.
\end{DoxyEnumerate}

Using Sys\+Tick for both would cause a deadlock if a HAL function with a timeout were ever called from a high-\/priority interrupt handler. \Hypertarget{main_8c_a840291bc02cba5474a4cb46a9b9566fe}\index{main.c@{main.c}!main@{main}}
