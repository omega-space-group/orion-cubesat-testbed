Task\textquotesingle{}s Handler where main logic is executed inside an infinite loop. 

Task blocks indefinitely and wakes up on a new msg pushed to its queue. Then the message is parsed and:\+
\begin{DoxyEnumerate}
\item If its a HB msg then subsystem status is locally updated
\item If not, then the new message and its associated topic are published through the software bus.
