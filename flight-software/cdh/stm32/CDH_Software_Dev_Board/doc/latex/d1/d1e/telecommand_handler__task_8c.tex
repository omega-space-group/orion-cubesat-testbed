Task\textquotesingle{}s Handler where main logic is executed inside an infinite loop. 

Telecommand Handling Logic:\+
\begin{DoxyEnumerate}
\item Subscribe to topics defined in \doxylink{subscriptions_8c}{subscriptions.\+c}
\item Set your own sync bit and block until all other tasks have finished initialization before continuing.
\item Enter infinite loop and set health bit (since task is not periodic).
\item Block indefinitely until a new message is pushed in the local queue.
\item Wake up and clear the health bit and begin execution.
\item Parse the command (Authenticate -\/\texorpdfstring{$>$}{>} Decode (Package then PUS))
\item Execute TC if valid.
\item Set health bit to 1 again and finish. \begin{DoxyNote}{Note}
For testing purposes, the handler responds only to TC to change state to SAFE or NOMINAL at the moment. 
\end{DoxyNote}
