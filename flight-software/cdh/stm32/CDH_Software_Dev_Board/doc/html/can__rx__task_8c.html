Detailed Description

Implementation of the CAN Rx Task responsible for parsing any received FDCAN messages.

Function Documentation

◆ CAN_RX_Handler()

void CAN_RX_Handler ( void * argument)
static

Task's Handler where main logic is executed inside an infinite loop.

Task blocks indefinitely and wakes up on a new msg pushed to its queue. Then the message is parsed and:

  1. If its a HB msg then subsystem status is locally updated
  2. If not, then the new message and its associated topic are published through the software bus.
    Parameters
    argumentPointer to task's local queue handle
