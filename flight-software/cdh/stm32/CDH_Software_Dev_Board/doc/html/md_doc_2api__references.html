1. Subscribe

void Subscribe(const char* name, QueueHandle_t queue);

📦 What it takes:

name: The task handler name as a string.

queue: The task's local queue handle (passed via the task's argument).

⚙️ How it works:

Calling this function does not wake up a task. It is just a normal function call inside the task.

⏱️ When to use it:

You should call this during the "boot" phase of the task, outside of the infinite loop, so it runs only once. After subscribing, all tasks must call TaskSync_SetAndWait() to sync up before moving forward.

📖 See Also:

For more details, check out the Task Creation and Initialization Manual.

2. Publish

void Publish(Message_t newMsg);
Message_t
Software Bus Message Structure.
Definition app_config.h:168

📦 What it takes:

newMsg: The message you want to publish.

⚙️ How it works:

Calling this does not wake up a task directly and acts like a normal function call. However, calling this will wake up the dispatcher task right away. This triggers a context switch, meaning the current task stops running and the dispatcher takes over (because in the original firmware, the dispatcher task has the highest priority).

3. Sleep

WakeupReason_t SleepUntil(QueueHandle_t queue, Message_t *newMsgRsc, TickType_t xTicksToWait);

📦 What it takes:

queue: The task's own local queue.

xTicksToWait: How long the task can stay blocked waiting for a message.
