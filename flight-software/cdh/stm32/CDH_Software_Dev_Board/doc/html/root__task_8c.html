Detailed Description

Implementation of the Root Task responsible for starting all peripherals and spawn (initialize) every task.

Function Documentation

◆ Root_Task_Handler()

void Root_Task_Handler ( void * argument)
static

Task's Handler where main logic is executed inside an infinite loop.

  1. All peripherals are started.
  2. Task sync event is initialized.
  3. Task health event is initialized.
  4. Each task is initialized.
  5. Task blocks forever.
    Warning
    To create a task.c/.h file with an init() and a handler() function does NOT mean the task will execute. Only tasks that are initialized in the Root Task are scheduled by the scheduler for execution.
