◆ HAL_FDCAN_RxFifo0Callback()

void HAL_FDCAN_RxFifo0Callback ( FDCAN_HandleTypeDef * hfdcan,
uint32_t RxFifo0ITs )

Callback function that handles new FDCAN messages.

Any new messages received by the peripheral that also pass any hardware filtering will trigger a hardware interrupt. This will wake up the IRQ Handler which in turn calls the callback function to handle the message. This includes:

  1. Popping the msg from the FDCAN Rx FIFO
  2. Pushing the new msg to CAN_Rx_Task's (can_rx_task.c) queue for parsing.
    Parameters
    hfdcanPeripheral's handle
    RxFifo0ITsRx FIFO to be used for pushing/popping new messages. Configured in MX_FDCAN1_Init().

References CAN_RX_Task_GetQueue().
